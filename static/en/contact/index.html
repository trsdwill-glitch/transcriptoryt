Report a transcription problem

Include the mode you selected, your browser and device, the approximate time, and the error code or stage shown. Describe the file type and approximate duration. For a server job, you can include its job identifier. Do not send API keys, cookies, confidential recordings or full transcripts. If a public media link is necessary to reproduce the issue, send it only if you have permission to share it.

Privacy, copyright and security

Explain your relationship to the material or issue and the action you are requesting. For a rights report, identify the work and the relevant location. For a security issue, describe the behavior without accessing or copying another user's content. We may ask for additional details needed to understand or verify a request.

Before you write

Server minutes and upload limits are shown in the tool. Server downloads normally expire after one hour. On this device requires a secure browser context and a supported audio file; the first transcription downloads the model. A blocked YouTube request can depend on YouTube or the server IP rather than your file.
