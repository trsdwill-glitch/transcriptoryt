      Frequently asked questions

      Is it free?

      Yes. On this device has no server-minute quota. Server mode is free within the current usage limits and shared operating budget.

      Do I need an account?

      No. You can start a transcription and download the result without signing up.

      Does it work on videos without captions?

      Server mode transcribes the audio with Whisper, so existing captions are not required. YouTube may block some downloads; only submit material you have permission to process.

      What are the limits?

      Up to 5 items per job, with a maximum of 500 MB and 120 minutes per file. In Server mode, each user can transcribe up to 120 minutes of audio in a rolling 24-hour period. The tool shows your remaining minutes. On this device processes one supported audio file at a time, without using server minutes; device memory and browser support still apply.

      Which formats can I download?

      Both modes export TXT, Markdown, DOCX, SRT and VTT. Server batches can be downloaded as a ZIP or combined into a single TXT, Markdown or DOCX file. Subtitle formats always include timestamps.

      Are my files stored?

      On this device keeps the selected audio and transcript in your browser. Server mode removes temporary audio when a job ends and normally offers the transcript download for one hour; physical cleanup can follow within about five minutes. See the privacy policy for provider handling and other retention.
