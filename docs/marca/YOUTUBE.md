## Primeros videos (Shorts de 30-60 s, grabación de pantalla con voz)

1. Cómo pasar un video de YouTube a texto gratis (pegar el enlace → descargar Word).
2. Crear subtítulos SRT para tu video en 1 minuto.
3. Transcribir una entrevista sin subir el audio (modo «En este dispositivo»).
4. Notas de voz de WhatsApp a texto.

Cada descripción tiene que empezar con el enlace a la página que corresponde. Ejemplo: Short 1 → `/youtube-a-texto/`.

Después de publicar el canal, envía la URL (`https://www.youtube.com/@transcriptoryt`) para añadirla al `sameAs` del schema de la web.
